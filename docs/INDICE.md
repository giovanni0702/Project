# Indice dei documenti

Una riga per file: cosa contiene e quando leggerlo. Aggiorna questa riga se cambia lo scopo di un documento.

| File | Contenuto | Leggilo quando |
|---|---|---|
| `STATO.md` | Iterazione, ultimi fatti, prossimi passi, blocchi | Sempre, a inizio sessione |
| `../TASKS.md` | Board dei task e decisioni richieste | Prendi o apri un task |
| `01-visione-e-scope.md` | Problema, prodotto, utente, scope | Dubbi su cosa è dentro o fuori |
| `02-concorrenza.md` | Concorrenti, punti deboli, nostro spazio | Scelte di prodotto, marketing |
| `03-privacy.md` | Vincoli privacy, dati raccolti, checklist | Qualsiasi modifica ai flussi di dati |
| `04-roadmap.md` | Iterazioni, criteri di uscita e di abbandono | Pianificazione, chiusura iterazione |
| `05-decisioni.md` | Registro decisioni (stack, modelli, mappa) | Prima di proporre un'alternativa |
| `06-dati.md` | Fonti dati, licenze, stato di verifica | Pipeline, variabili del modello |
| `07-report-watchdog.md` | Ultimo ciclo di controllo | Inizio iterazione |
| `08-ux.md` | Flussi, schermate, testi IT/EN | Lavoro sull'app |

| `10-release.md` | Requisiti store e checklist | Build, beta, pubblicazione |

| `13-rischi.md` | Registro dei rischi | Pianificazione, watchdog |

| `16-grafica.md` | Sistema visivo, token, link alle schermate | Lavoro su interfaccia e bozze |
| `17-autonomia.md` | Ciclo autonomo, limiti, definizione di "beta valida" | Ogni ciclo, pianificazione |
| `18-nota-tester.md` | Bozza di nota informativa per i tester | Preparazione della beta |
| `fonti.md` | Cache delle ricerche web con scadenza | Prima di ogni ricerca web |
| `archivio/` | Task chiusi delle iterazioni passate | Quasi mai |
